- query：上海到杭州车次与杭州天气均实际查询，不创建计划。

- multicity：一份计划，上海→杭州→南京→上海三段，实际选中3条车次和2处酒店地点，保存至少2场活动。酒店报价、库存和企业政策缺口明确保留；通过表示执行与持久化达到请求的可实现范围。
