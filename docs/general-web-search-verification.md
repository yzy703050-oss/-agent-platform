## 实际模型计量

模型均为本地配置的 deepseek-flash；数据库真实，Eino 实际流式执行，tokens 取供应商 Usage，各次模型请求计一次，重复流式 usage 取该请求最大值而非相加。记录器不增加模型请求。耗时包含 Manager 提交、Agent/工具执行至 PostgreSQL 终态读取，不含浏览器和 HTTP/SSE 传输；单次样例不能代表分位数或平均性能。
