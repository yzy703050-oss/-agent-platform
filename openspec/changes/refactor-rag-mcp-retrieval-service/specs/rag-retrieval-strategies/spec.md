## Purpose

通过知识库管理的默认策略统一执行检索，让 Host 获得可引用、可解释的证据，并在不隐式改写问题或改变正常查询行为的前提下，为分块、召回、重排和时间感知提供可复现的后台实验能力。

## ADDED Requirements

### Requirement: 知识库默认混合策略
正常查询 SHALL 由知识库默认策略执行，首版统一为 Dense + BM25 混合召回与 RRF 融合。后台 SHALL 能记录查询类型到策略的显式绑定；首版所有已启用类型使用同一混合配置。未绑定类型 SHALL 回到知识库默认策略，不自动推断查询范围或选择另一算法。

#### Scenario: Host 只传业务查询
- **WHEN** Host 使用已有查询参数，或附带未单独绑定的查询类型
- **THEN** 使用该知识库默认混合策略；结果记录传入类型及实际策略版本

#### Scenario: Host 试图覆盖算法
- **WHEN** Host 试图直接指定分块器、召回算法、模型、权重或物理集合
- **THEN** 按工具契约拒绝未知控制参数，不改变知识库默认配置

### Requirement: 策略具有不可变版本
每次查询 MUST 固定并记录实际使用的策略版本、索引版本及语料可见性版本。后台修改配置 SHALL 生成新版本，失败的配置发布不得替换原有效配置；历史实验使用原配置快照。

#### Scenario: 查询期间修改配置
- **WHEN** 管理员调整 Rerank 或时间权重并发布
- **THEN** 进行中的查询仍使用原快照，后续查询使用新版本，历史记录不被重新解释

### Requirement: Query 改写归调用方
RAG SHALL 使用 Agent 提供的 Query 进行检索，不另行调用模型做语义改写、问题拆解或自主补查。分词、向量编码和格式规范化 SHALL 保留查询意图；Query 文本中的过滤语法不得扩大授权范围或切换知识库。

#### Scenario: 需要补查
- **WHEN** 一次检索没有足够证据
- **THEN** RAG 返回本次真实结果和缺口，由 Agent 决定是否改写并发起下一次查询

### Requirement: 融合后精细重排
知识库 SHALL 支持配置 Rerank，正常默认配置启用已验证的重排模型。检索 SHALL 保留候选集完成精细相关性评分和可选时间融合后，再截取最终 Top-K；各阶段数量与分数转换 SHALL 可追踪。

#### Scenario: 正确时间版本初排靠后
- **WHEN** 正确片段进入候选集但不在基础排序前五名
- **THEN** 它仍能参与配置范围内的重排和时间融合，不因最终输出数量提前被丢弃

### Requirement: 可选时间融合
知识库 SHALL 配置时间融合开关与版本化算法。QET 由 Agent 显式提供，QIT 由 Host 程序提供或由服务接收时间补齐并标注来源。缺少 QET 时首版 SHALL 跳过时间排序；缺少可靠 DET 时不得以入库时间冒充有效期，须标注未知和实际回退。时间分数不得被解释为有效性概率。

#### Scenario: 历史问题和晚入库政策
- **WHEN** 用户现在查询过去日期，相关政策在该业务日期之后才导入
- **THEN** 不仅因 DIT 晚于 QET 就判定条款无效；根据真实条款时间评分，并保留入库时间及实际算法信息

#### Scenario: 时间条件缺失
- **WHEN** 调用方未提供 QET
- **THEN** 按相关性顺序返回并标记时间阶段未执行，不静默假定目标时间为今天

#### Scenario: 条款时间不匹配
- **WHEN** 候选条款的可靠有效期与 QET 不相交
- **THEN** 标注不匹配，不因其在候选集中时间分数最高而声称适用；首版默认软排序，只有后台明确配置的有效期过滤策略才作硬过滤

### Requirement: 后台消融和原文证据评测
服务 SHALL 复用后台评测入口，支持配置 Dense、BM25、混合、Rerank 开关和时间融合开关用于实验；这些实验不得直接改写正常知识库默认策略。每次实验 MUST 保存语料与评测集版本、Agent 改写后 Query、时间条件、配置快照、各阶段证据、质量指标、耗时和错误。

#### Scenario: Rerank 与时间融合消融
- **WHEN** 后台运行二者分别开关的四组实验
- **THEN** 使用相同语料、Query、时间条件和候选生成配置，记录各组实际执行路径；降级或失败不计作完整策略成功

#### Scenario: 不同分块策略比较
- **WHEN** 切分边界和片段 ID 发生变化
- **THEN** 通过文档版本及原文证据范围评估命中和覆盖，分别报告候选召回、最终排序、错误时间版本比例和耗时，不直接比较不同评分器的原始分数
