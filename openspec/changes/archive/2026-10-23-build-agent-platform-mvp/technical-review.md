## 边界检查

| 检查项 | 文档结论及对应位置 |
| --- | --- |
| Service / Agent 并列 | design D1；Application 组织用例，不直接访问具体 Repository |
| 业务授权复用 | design D10；get_my_settings 经 SettingsService；运行身份不能被模型指定 |
| 唯一执行状态所有者 | design D5；RunManager 迁移状态，执行器只报告结果 |
| Eino 恢复与平台恢复分离 | design D6；先验证真实 Eino，Store 仅适配 opaque payload |
| 订阅与页面存活分离 | design D7、D9；切 SSE 不暂停，页面租约负责离线 |
| 单实例重启安全 | design D3、D7；启动锁与 attempt 围栏，不重放未知外部操作 |
| 旧任务上下文隔离 | design D8；历史完整，模型只读取有效任务组 |
| 远程差旅 | design D10；仅预留，未来通过平台内部 API 存储，不重复运行 Eino |
| 依赖和基础设施 | design D2、D11；固定 Eino 版本，不以缺数据库为由改用内存产品存储 |

## 已修正的问题

1. 页面租约最初只有行为描述，缺少数据库对象；已补 page_leases 及迁移任务。
2. 请求摘要未明确排除 page_id；已明确跨页面幂等返回原 Run，不借重试改变执行归属。
3. 新标签页可能复制 sessionStorage；改为每个新文档实例生成页面身份，页面内切换保持身份。
4. 内核因暂停退出不能进入普通失败收尾；已明确由平台请求原因和真实退出结果共同判定。
5. 计划的运行数据库变量命名不一致；统一 DB_DSN，测试单独使用 TEST_DATABASE_URL。
6. 补充页面身份、运行配额及跨页面幂等的测试案例。
