## Purpose

为平台通用聊天提供按需获取公开网络信息的能力，使用户能够看到搜索执行状态和可核对的来源，同时约束输入、外部调用和上下文大小，并在查询失败时得到清楚反馈，沿用平台既有任务恢复与数据隔离规则。

## ADDED Requirements

### Requirement: 按需搜索与服务端开关
系统 SHALL 为通用聊天提供 `web_search`，由模型根据用户要求和信息时效需求决定是否调用；普通问答不强制搜索。服务端开关 `WEB_SEARCH_ENABLED` 默认 true，设置为 false 时不向模型暴露搜索工具，也不在提示中宣称可搜索。搜索不增加差旅工具或主 Agent 委派。

#### Scenario: 用户明确要求联网
- **WHEN** 搜索已启用且用户明确要求查找公开网络信息
- **THEN** 模型获得搜索工具及相应使用指导，并可通过工具结果继续作答

#### Scenario: 关闭搜索或普通问答
- **WHEN** 管理员关闭搜索，或模型回答无需外部资料的普通问题
- **THEN** 关闭时不注册搜索工具；普通问答允许直接回复且不必产生搜索调用

### Requirement: 搜索输入与结果有界
工具 SHALL 仅接受 query 和可选 time_range；query 去首尾空白后为 1～500 个 Unicode 字符，time_range 为缺省/空字符串、d、w、m、y。无效参数返回可理解的纠正信息且不访问外部服务。每次结果最多 5 条，每条含 title、url、summary；标题最多 200 字符、摘要最多 800 字符、URL 最多 2048 字节，整体工具 JSON 最多 16384 字节，超限时减少结果而不截断 JSON。来源仅允许有效 http/https URL，空项、重复 URL 和其他协议被剔除。

#### Scenario: 参数放错位置
- **WHEN** 模型提供未知字段、缺失或空 query、超长 query 或不支持的时间范围
- **THEN** 工具不发网络请求，返回 invalid_arguments 和字段要求，允许模型在既有迭代预算内纠正

#### Scenario: 结果过大或 URL 不可展示
- **WHEN** 搜索返回过多、超长、重复或非法来源的内容
- **THEN** 工具按既定限额整理有效结果，返回完整 JSON，不把非法来源显示成链接

### Requirement: 失败反馈与可观察执行
系统 MUST 区分成功、没有结果和搜索不可用；超时、服务拒绝、网络失败和异常响应不得伪装成成功。工具使用既有 TOOL_SECONDS 和父任务取消信号，不新增自动重试循环；模型后续是否再调用受既有迭代预算约束。每次工具调用产生开始及完成或失败事件，包含名称、耗时及状态码，不把原始 HTML 或请求凭证放入事件。

#### Scenario: 外部不可用
- **WHEN** 服务限流、拒绝、连接失败、超时或返回无法识别的搜索页面
- **THEN** 返回 search_unavailable 或 search_timeout 的结构化反馈并产生 tool.failed，提示模型如实说明此次搜索未成功；不据此生成伪造来源

#### Scenario: 用户结束任务
- **WHEN** 搜索正在进行而父任务被取消
- **THEN** 取消传到网络请求，工具不启动独立后台重试，取消后的结果不能把任务改回成功

#### Scenario: 没有匹配结果
- **WHEN** 可识别的正常搜索响应没有有效结果
- **THEN** 返回 no_results 和空结果列表，前端与模型不将其解释为已有搜索依据

### Requirement: 可核对来源与不可信外部内容
系统 SHALL 将搜索结果作为参考资料而非系统指令。模型使用搜索结果作答时应按提示给出对应来源 URL；不得声称已读取未抓取的网页正文。前端展示搜索中、搜索完成或搜索失败，并在工具结果中展示标题、摘要与安全的来源链接；其他工具维持各自显示。

#### Scenario: 使用搜索资料作答
- **WHEN** 搜索得到有效资料且模型据此回答
- **THEN** 模型收到来源引用要求，用户可从工具结果直接打开来源；外部摘要中的行为指令不具有平台指令权限

#### Scenario: 搜索事件展示
- **WHEN** 前端收到当前 Run/attempt 的 web_search 工具事件
- **THEN** 使用联网搜索文案，不显示成差旅工具；旧 Run/attempt 事件仍按原规则过滤

### Requirement: 搜索历史与恢复兼容
系统 MUST 沿用已有授权消息及事件存储记录搜索调用和结果，浏览历史不重新搜索；已保存的工具结果可随有效断点继续使用。搜索开关、工具契约、提示或组件版本变化必须反映在执行兼容指纹中，不兼容断点不能静默恢复。暂停任务被新问题替代时，其搜索结果按原规则排除出新任务上下文。

#### Scenario: 历史与恢复
- **WHEN** 用户重开包含搜索结果的会话或从兼容断点继续
- **THEN** 浏览只读取既有记录；恢复保留已完成工具结果，不为了重画页面重复调用搜索

#### Scenario: 搜索配置改变
- **WHEN** 搜索开关或执行兼容指纹变化后尝试恢复旧任务
- **THEN** 按既有不兼容断点规则拒绝恢复，保留历史可查看
